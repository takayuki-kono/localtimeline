# Pomodoro 仕様

## 概要

ポモドーロタイマー（`pomodoro.py`）の動作仕様。フォーカス時間・休憩時間・タスク一覧は `tasks.md`。休憩中の**音の候補**は `sheet_config.json`（Sheets 用設定と同一ファイルに同居）。

## 設定ファイル tasks.md

- **設定セクション（先頭）**: キーで値を指定。未指定時はデフォルト。
  - `focus_minutes`: フォーカス時間（分）。省略時 25。
  - `break_minutes`: 休憩時間（分）。省略時 5。
  - `break_sound_volume`: 休憩中 WAV の音量（`0.0`〜`1.0`）。省略時 1.0（最大）。
- **Tasks セクション**: `# Tasks` 以降にタスク一覧（`- [ ] タスク名` または `- タスク名`）。

## タスク選択

- タスク一覧は `tasks.md` の Tasks セクションから読み込む。
- フォーカス開始時に選択されているタスクがログに記録される。

## タスクの自動進み（スイッチング）

- **トリガー**: タスク選択画面に戻ったとき（休憩終了後、またはタイマーリセット後）。
- **動作**: 直前まで選択していたタスクの**次のインデックス**のタスクを自動で選択する。
- **ループ**: リストの最後のタスクの次は、先頭（インデックス 0）に戻る。
- **実装箇所**: `reset_to_task_selection()` 内で `show_task_screen()` の後に、`self.selected_task` の index+1 を `task_var` に設定。

## 休憩中の音声

- **休憩タイマー画面（`BREAK` 表示中）**に **休憩の音** 用プルダウンを表示する（タスク選択画面には出さない）。休憩タイマーが**動いている間**だけ、選択に応じて WAV をループ再生する。
- 候補は **`sheet_config.json`** のキー **`break_sound_options`**（配列）で定義する。各要素はオブジェクト:
  - **`label`**: 画面に出す名前（必須）
  - **`file`**: `pomodoro.py` と同じディレクトリにある WAV のファイル名。**`null` または空文字**は無音（再生なし）
- **初期選択（デフォルト）**: `file` が設定されている項目のうち**先頭**の `label`（現状 `3kHz40Hz1min`）。該当が無い場合は配列の**先頭**の `label`。
- `sheet_config.json` が無い・JSON が壊れている・キーが無い場合は、**`無音（再生なし）` のみ**の1項目として扱う。
- ファイルが無い場合は再生をスキップする（エラーで止めない）。
- **音量**: `tasks.md` の `break_sound_volume`（`0.0`〜`1.0`）で調整する。再生中は Windows の wave 出力音量（`waveOutSetVolume`）を一時的に変更し、**元の WAV ファイルをそのまま**ループ再生する（IEEE float WAV も可）。休憩終了時に音量設定を元に戻す。
- 休憩終了・早めに止める・タスク選択に戻るときに再生を停止する（`winsound` の `SND_PURGE`）。
- **評価（1–10）送信後**は休憩タイマーは**停止状態**で表示される。クリックで開始すると同時に音声再生も始まる。
- **BREAK 画面を表示するとき**に `sheet_config.json` を読み直し、候補が変わっていればプルダウンを更新する（選択中の `label` が消えた場合はデフォルトに戻す）。
- **Git**: 長尺 WAV（例: `1kHz40Hz10min.wav`）は GitHub の 100MB 制限に抵触するためリポジトリに含めない。`.gitignore` で除外し、手元にだけ置く。

## 画面フロー

1. タスク選択 → Start Focus → タイマー（Focus）→ 評価（1–10）→ 休憩タイマー（Break）→ タスク選択（**次のタスクが自動選択**）
2. 右クリックでリセットした場合もタスク選択に戻り、同様に次のタスクが自動選択される。
