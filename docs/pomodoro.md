# Pomodoro 仕様

## 概要

ポモドーロタイマー（`pomodoro.py`）の動作仕様。設定は `tasks.md` に集約する（設定全般）。

## 設定ファイル tasks.md

- **設定セクション（先頭）**: キーで値を指定。未指定時はデフォルト。
  - `focus_minutes`: フォーカス時間（分）。省略時 25。
  - `break_minutes`: 休憩時間（分）。省略時 5。
- **Tasks セクション**: `# Tasks` 以降にタスク一覧（`- [ ] タスク名` または `- タスク名`）。

## タスク選択

- タスク一覧は `tasks.md` の Tasks セクションから読み込む。
- フォーカス開始時に選択されているタスクがログに記録される。

## タスクの自動進み（スイッチング）

- **トリガー**: タスク選択画面に戻ったとき（休憩終了後、またはタイマーリセット後）。
- **動作**: 直前まで選択していたタスクの**次のインデックス**のタスクを自動で選択する。
- **ループ**: リストの最後のタスクの次は、先頭（インデックス 0）に戻る。
- **実装箇所**: `reset_to_task_selection()` 内で `show_task_screen()` の後に、`self.selected_task` の index+1 を `task_var` に設定。

## 休憩中の音声

- `pomodoro.py` と同じディレクトリの **`1kHz40Hz1min.wav`** を、休憩タイマーが**動いている間**に再生する。
- ファイルが無い場合は再生をスキップする（エラーで止めない）。
- 休憩終了・早めに止める・タスク選択に戻るときに再生を停止する（`winsound` の `SND_PURGE`）。
- 休憩が音声より長い場合はループ再生する。
- **Git**: 長尺 WAV（例: `1kHz40Hz10min.wav`）は GitHub の 100MB 制限に抵触するためリポジトリに含めない。`.gitignore` で除外し、手元にだけ置く。

## 画面フロー

1. タスク選択 → Start Focus → タイマー（Focus）→ 評価（1–10）→ 休憩タイマー（Break）→ タスク選択（**次のタスクが自動選択**）
2. 右クリックでリセットした場合もタスク選択に戻り、同様に次のタスクが自動選択される。
